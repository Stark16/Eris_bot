# Eris_bot
> A fun side project on a discord bot for my DnD Group
> The bot was inspired by one of the most populor NPCs in our campaign
# Bot commands:
* The bot has command prefix `!E`.
* `/whoami`: has a custom line for each server member referencing the NPCs interaction with their player chatacter from the campaign
* `/john`: returns a randome *excuse* as it was an inside joke that I make excuses whenever I have a bad play.
